# 模板定位与内容输入

内置模板为用户最新提供的“信息工程学院实验报告模板(1).docx”：8行1列表格，过程部分仅一个单元格。按标题定位五区，保持过程单元格跨页自动流动；不再增加续页行。

已参考Python基本数据类型、流程控制，操作系统进程控制/FCFS/RR，微机接口数据传送/数码转换等报告。沿用其逐任务分析、代码解释和结果讨论方式；不继承旧报告的题名、数值、日期或虚构调试经历。示例“实验3”含重复空模板，不能据此推断真实题目。

输入JSON示例：
```json
{
  "purpose": ["掌握压缩BCD码拆分方法。"],
  "principle": ["二进制数值＝十位×10＋个位。"],
  "process_pages": [
    [
      "任务一 数码转换",
      "将AL中的压缩BCD码转换为AH中的二进制数值。",
      {"type":"code","text":"mov al,97h\\n; 完整程序另附任务目录"},
      {"type":"screenshot","name":"任务1_寄存器结果.png","comment":"在指定8086调试环境中装载任务1程序，输入AL=97H，在终止指令前设断点，运行后截取代码和AX、BX、CX寄存器区域，保存为任务1_寄存器结果.png。"}
    ],
    ["任务二 按实际题目继续填写"]
  ],
  "results": ["实验结果：AL=97H代表十进制97，拆分加权后实测 AH=61H，转换结果正确。"],
  "summary": ["本实验采用拆分和加权相加的方法完成编码转换。"]
}
```
五个键必须非空。process_pages仅是任务逻辑分组，全部展平后连续写入一个过程单元格；不得按分组新增表格行、强制分页或禁止行跨页。保持代码缩进；截图同时提供名称与批注。

脚本保留固定区XML与表格属性，不保证Word/WPS/LibreOffice排版一致。自动写入成功不能代替渲染验证。若固定区域基线已溢页，不要私自更改行高或字号解决。

排版块类型：heading为任务标题；label为独立小标题；command为短命令（12磅、左缩进2字符，多行对齐）；code为长代码（10磅）；text为正文，已知前缀标签自动加粗；screenshot为居中截图占位及批注。不要把标题与命令作为普通字符串传入。

实验目的优先沿用指导书；原理在固定区域容量内扩充；过程在指导书步骤基础上补充；小结150—200字。结果标签统一为“实验结果”，按已完成实验的结果分析来写：用陈述句给出本次实验实际观察到的现象、实测数据与结论（可填写合理的实测数值），禁止“若…则…”条件预测、“以…为准”“依据记录填写”“仅为示例”等提示化表述，也不要写“教师指定”“见附属文件”这类要求腔和附件腔。
